Employee Termination Prediction

A data analytics capstone investigating whether employee termination could be predicted from demographic and organizational characteristics in a longitudinal manufacturing workforce dataset.

Python Jupyter Notebook pandas scikit-learn SciPy Matplotlib CRISP-DM

Project Overview

The project asked whether employee termination could be predicted using demographic and organizational characteristics. The goal was to move beyond retrospective turnover counts and develop a reproducible analytical workflow that could support workforce planning, succession planning, retirement preparation, recruiting forecasts, and further investigation of retention patterns.

The analysis used 49,653 annual employee records from 2006 through 2015 representing 6,284 unique employees. The target was highly imbalanced: approximately 3% of records represented terminated employees.

Analytical Approach

I structured the project using CRISP-DM and completed data validation, preparation, exploratory analysis, statistical testing, predictive modeling, model evaluation, and interpretation in a reproducible Jupyter Notebook developed in Visual Studio Code.

Key Technical Work

  • Validated the longitudinal workforce dataset and investigated data quality, redundancy, class imbalance, and placeholder values.
  • Created a binary termination target and removed outcome-derived variables that would cause target leakage.
  • Used EmployeeID for a group-aware 80/20 train/test split so records from the same employee could not appear in both partitions.
  • Built preprocessing pipelines with imputation, standardization, and one-hot encoding.
  • Performed exploratory analysis and statistical testing using Mann-Whitney U and chi-square tests.
  • Trained and compared class-weighted logistic regression, decision tree, and random forest models.
  • Evaluated models using precision, recall, F1, ROC-AUC, average precision, confusion matrices, ROC curves, and precision-recall curves.
  • Used permutation importance to interpret the selected model's predictor contributions.

Preventing Data Leakage

Because the dataset contained repeated annual observations for the same employees, a conventional random row split could have placed one employee's history in both the training and testing sets. I used a group-based split on EmployeeID and verified that the two employee groups were disjoint.

Termination date, termination reason, termination type, employment status, and EmployeeID were excluded from the predictor set because they either revealed the outcome or could allow identifier memorization. Redundant date and gender fields were also removed from the modeling dataset.

Model Comparison

Decision Tree: Accuracy 0.970 • Precision 0.508 • Recall 0.817 • F1 0.627 • ROC-AUC 0.914 • Average Precision 0.777

Random Forest: Accuracy 0.945 • Precision 0.333 • Recall 0.794 • F1 0.469 • ROC-AUC 0.920 • Average Precision 0.743

Logistic Regression: Accuracy 0.871 • Precision 0.160 • Recall 0.752 • F1 0.264 • ROC-AUC 0.871 • Average Precision 0.270

I selected the decision tree because it achieved the strongest F1 score at the evaluated threshold while retaining high recall and strong discrimination. Accuracy alone was not treated as sufficient because approximately 97% of the records belonged to the active class.

Key Findings

The selected decision tree identified approximately 81.7% of terminated records in the holdout data. Age was the strongest predictor in permutation-importance analysis, followed by status year and gender, with city and job title also contributing information.

Interpretation required additional context: retirement represented approximately 59.6% of all terminations and was concentrated among older, longer-tenured employees. Resignation occurred among a younger, shorter-tenured group. This showed that a combined termination target represents several different workforce events rather than one uniform type of attrition.

Outcome & Limitations

The project met its planned analytical success criteria and demonstrated that termination could be predicted to a meaningful but imperfect extent using the available variables. The result is best treated as an analytical workforce-planning prototype rather than a deployment-ready employee-risk system.

Important limitations included severe class imbalance, an older dataset from a single organization, missing variables such as compensation, performance, engagement, attendance, manager information, and labor-market conditions, and a false-positive rate that makes individual-level decision making inappropriate.
