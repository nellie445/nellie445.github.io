StackGrow Inventory Management System

A university software-engineering team project developed for Feed Fertiliser and More, an agricultural retail business. The project focused on replacing inefficient manual inventory processes with a structured inventory management application.

Project Coordination Data Cleaning Requirements Gathering Debugging Technical Documentation Java Excel

Project Overview

Feed Fertiliser and More relied heavily on manual inventory processes and spreadsheets. The StackGrow team designed an inventory management system to improve how the business stored, accessed, searched, and updated information relating to inventory, suppliers, employees, and sales.

The completed system used a layered architecture incorporating the user interface, authentication and authorization, application logic, and a database layer. Excel-based business data was used to populate records used by the application.

My Role

I served as one of the project's group leaders while also contributing to the data, documentation, requirements, and quality-assurance aspects of the project.

Key Contributions

  • Co-led the project team and helped coordinate responsibilities and project activities.
  • Assigned and tracked team responsibilities and helped keep the project moving toward scheduled deliverables.
  • Participated in client communication and requirements gathering to understand the business's existing inventory process and needs.
  • Cleaned and prepared project data for use within the inventory-management workflow.
  • Performed debugging and troubleshooting as part of the project's assigned debugging team.
  • Contributed to technical and project documentation, including review and correction of the Software Requirements Specification (SRS) and Software Design Specification (SDS).
  • Helped compile the project's final documentation and presentation materials.

Requirements & Data

Requirements were gathered through discussions and an interview with the business owner. The team used this information to define the application's functionality and determine how the existing inventory workflow could be represented within the system.

The project's database layer used information drawn from Excel to populate inventory, supplier, and employee records. My data contribution included cleaning and preparing project data so it could be used within this workflow.

System Functionality

Inventory Management

The system was designed to allow authorized users to view, add, edit, delete, categorize, and search inventory records.

Business Records

The application also incorporated supplier and employee records, sales information, reporting capabilities, and different levels of user access.

Project Process

The team worked through requirements elicitation, system specification, architecture planning, development, documentation, testing, and debugging. Regular team meetings were used to assign responsibilities, review progress, discuss implementation decisions, and troubleshoot issues as development progressed.
