JHANELL PORTFOLIO STARTER

What is this?
This folder is a simple static website. You do not need to install anything to view it.

How to preview it on your computer:
1. Open this folder.
2. Double-click index.html.
3. It should open in your normal web browser.
4. Click the project cards to test them.
5. Use the back links to return to the homepage.

Files:
- index.html = homepage
- style.css = visual styling
- projects/stackgrow.html = StackGrow case study
- projects/hurricane.html = hurricane data case study
- projects/internship.html = internship case study

Nothing in this starter site is permanently published yet.
We will revise the content first, then publish it through GitHub Pages.
